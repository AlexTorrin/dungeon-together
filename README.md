# Dungeon Togethere

Пошаговый 2D dungeon crawler в духе Pixel Dungeon с кооперативом на 1–4 игроков.
TypeScript, Phaser 3, pnpm-монорепо. Сеть (Colyseus) ещё не подключена — пока всё работает локально.

## Быстрый старт

```bash
pnpm install
pnpm dev          # клиент на http://localhost:5173 и игровой сервер на :2567
pnpm dev:client   # только клиент (одиночной игре сервер не нужен)
pnpm dev:server   # только сервер
```

Сетевая игра: меню → «⚔ Сетевая игра» → создать комнату и сказать друзьям код из 4 букв, они —
«Войти по коду». Над героями — имена из лобби (ваше — жёлтым). Пропала сеть или перезагрузили страницу — сервер ждёт 30 с: сеть вернётся сама, а после
перезагрузки в меню будет «↩ Вернуться в игру». Друг в локальной сети открывает `http://<ваш-ip>:5173`: клиент ищет сервер на
том же хосте (другой адрес — переменная `VITE_SERVER_URL`).

Проверки (должны быть зелёными после любых изменений):

```bash
pnpm typecheck
pnpm test
pnpm lint
pnpm format       # prettier --write
```

## Правила

Игра на угадывание. Все одновременно выбирают по два действия — шаг в одну из 8 сторон, удар по
клетке или ожидание, — потом ход разрешается в две фазы. Удар бьёт клетку по позициям **после** шагов: угадал,
куда отойдёт монстр, — попал; отошёл из-под удара — увернулся. Бить можно и пустое место.
Монстры живут по тем же правилам и тоже угадывают; их намерения не видны. Оружие: нож (урон 3,
соседняя клетка), лук (урон 2, радиус 4), меч (урон 6, соседняя клетка, но удар — 2 ОД: замах на
весь ход), волшебная палочка (урон 3, радиус 6), без оружия — кулаки (урон 1). Наступил на
предмет — он в рюкзаке (4 места); взять в руки или выбросить — действие за 1 ОД.
С уровня два выхода: убить всех монстров или найти ключ (он у одного из монстров) и открыть
дверь-выход. Монеты (2–3 за уровень) лежат на полу и выпадают из монстров. Погиб — всё, что
нёс, потеряно. Сложность выбирается в меню: легко, средне, трудно.
Между забегами — лагерь: магазин (нож и лук по 2 монеты, продажа любого оружия за полцены) и
сундук. В забег герой берёт то, что в руках и в рюкзаке, и этим рискует; кошелёк и сундук в
безопасности. Первый забег — с пустыми руками. Esc в забеге дважды — бросить его (вещи пропадут).
Демо-комната и свои комнаты — тренировка: без снаряжения, добыча не сохраняется.
Профиль (кошелёк, снаряжение, сундук) хранится на игровом сервере, поэтому для забегов и лагеря
нужен запущенный сервер (`pnpm dev` поднимает его вместе с клиентом); тренировкам он не нужен.
Видно только то, что в поле зрения команды (радиус 8, стены закрывают обзор): исследованное, но
невидимое затемнено, монстров там не видно. Монстры тоже замечают вас, только если видят.
Подробно — в [docs/architecture.md](docs/architecture.md).

## Управление

| Что                 | Как                                                                                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Выбрать шаг         | WASD или стрелки; две клавиши сразу — по диагонали (W+A — вверх-влево)                                                                                                                     |
| Выбрать удар рядом  | Shift + направление (пока Shift зажат, видно, куда можно ударить)                                                                                                                          |
| Прицел (любой удар) | F, затем WASD/стрелки двигают курсор, Tab — следующая цель, Enter — ударить, F/Esc — выйти                                                                                                 |
| Взять в руки        | 1–4 — предмет из слота рюкзака (1 ОД)                                                                                                                                                      |
| Выбросить           | Q — из рук, Shift+1–4 — из рюкзака (1 ОД), предмет падает на вашу клетку                                                                                                                   |
| Открыть дверь       | E — стоя рядом с дверью, нужен ключ (1 ОД); шагнуть в открытую дверь — выйти с добычей                                                                                                     |
| Ждать               | Пробел                                                                                                                                                                                     |
| Убрать последнее    | Backspace                                                                                                                                                                                  |
| Подтвердить ход     | Enter (если выбрано одно действие, второе — ждать)                                                                                                                                         |
| Мышь                | клик по клетке → «Ударить / Идти / Ждать / Отмена»: пункт добавляет действие в план, заполнил план — ход подтверждён; «Идти» к дальней клетке — сразу 2 шага, дальше путь продолжается сам |
| Двойной клик        | сразу ход без меню: по полу — шаги к клетке (дальше путь продолжается сам), по врагу — шаг к нему и удар (рядом — два удара, далеко — два шага навстречу), по себе — ждать                 |
| Очистить план       | ПКМ или Esc (если план уже отправлен, а ход не разрешён — отзывает его)                                                                                                                    |
| Выйти               | Esc (когда план пуст); в забеге — Esc дважды, бросить забег (несённое пропадёт)                                                                                                            |

**Ход — 2 действия** (2 очка действия): первое выбранное — фаза 1, второе — фаза 2, следующие
заменяют второе. Каждое действие выбирается от клетки, куда герой придёт после предыдущего.
Выбранный план рисуется полупрозрачными стрелками с номерами фаз, подтверждённый — сплошными и с ✓.

Редактор: ЛКМ — рисовать текущим инструментом, ПКМ — стена, `1`–`0` — стена/пол/старт/скелет/череп/
вампир/нож/лук/меч/палочка, во втором ряду — дверь, монета, ключ (пол стирает монстров, вещи и дверь), `T` — запустить комнату, `Esc` — в меню.
Кнопки `Ш±`/`В±` меняют размер (3…64).

## Структура

```
packages/
  shared/    логика игры: чистые детерминированные функции, без Phaser/DOM/Node
  client/    Phaser + Vite: сцены, рендер, ввод, UI. Никакой игровой логики
  server/    Colyseus: комнаты на 1–4 игроков, вызывает shared, рассылает состояние
assets/      графика из 2D Pixel Dungeon Asset Pack v2.0 (не редактируем; описание — docs/assets.md)
  custom/    свои спрайты в стиле пака (нож, стены под все сочетания соседей)
docs/        архитектура и заметки
tools/       sprites/ — скрипты, которые рисуют свои спрайты (knife.mjs, walls.mjs)
.claude/     скил run-game для запуска и проверки игры агентом (Claude Code)
```
