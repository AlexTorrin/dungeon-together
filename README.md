# Dungeon Togethere

Пошаговый 2D dungeon crawler в духе Pixel Dungeon с кооперативом на 1–4 игроков.
TypeScript, Phaser 3, pnpm-монорепо. Сеть (Colyseus) ещё не подключена — пока всё работает локально.

## Быстрый старт

```bash
pnpm install
pnpm dev          # клиент на http://localhost:5173
```

Проверки (должны быть зелёными после любых изменений):

```bash
pnpm typecheck
pnpm test
pnpm lint
pnpm format       # prettier --write
```

## Правила

Игра на угадывание. Все выбирают действие одновременно — шаг в одну из 8 сторон, удар по клетке
или ожидание, — потом ход разрешается разом. Удар бьёт клетку по позициям **после** шагов: угадал,
куда отойдёт монстр, — попал; отошёл из-под удара — увернулся. Бить можно и пустое место.
Монстры живут по тем же правилам и тоже угадывают; их намерения не видны. Оружие подбирается,
если на него наступить: ближнее бьёт соседнюю клетку (урон 3), дальнее — любую в радиусе 4 при
прямой видимости (урон 2), без оружия — кулаки (урон 1). Победа — когда убит последний монстр.
Подробно — в [docs/architecture.md](docs/architecture.md).

## Управление

| Что                 | Как                                                                                                                                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Выбрать шаг         | WASD или стрелки; две клавиши сразу — по диагонали (W+A — вверх-влево)                                                                         |
| Выбрать удар рядом  | Shift + направление (пока Shift зажат, видно, куда можно ударить)                                                                              |
| Прицел (любой удар) | F, затем WASD/стрелки двигают курсор, Tab — следующая цель, Enter — ударить, F/Esc — выйти                                                     |
| Ждать               | Пробел                                                                                                                                         |
| Подтвердить ход     | Enter                                                                                                                                          |
| Мышь                | клик по клетке → «Ударить / Идти / Ждать / Отмена» — выбор и есть подтверждение; к дальней клетке — шаг за шагом, следующий шаг выбирается сам |
| Отменить выбор      | Esc или ПКМ                                                                                                                                    |
| Выйти               | Esc (когда ничего не выбрано)                                                                                                                  |

Выбранное, но не подтверждённое действие рисуется на карте полупрозрачной стрелкой, подтверждённое —
сплошной и с ✓.

Редактор: ЛКМ — рисовать текущим инструментом, ПКМ — стена, `1`–`8` — стена/пол/старт/скелет/череп/
вампир/ближнее/дальнее (пол стирает монстров и предметы), `T` — запустить комнату, `Esc` — в меню.
Кнопки `Ш±`/`В±` меняют размер (3…64).

## Структура

```
packages/
  shared/    логика игры: чистые детерминированные функции, без Phaser/DOM/Node
  client/    Phaser + Vite: сцены, рендер, ввод, UI. Никакой игровой логики
  server/    (ещё нет) Colyseus — появится на шаге 6 roadmap
assets/      графика из 2D Pixel Dungeon Asset Pack v2.0 (не редактируем; описание — docs/assets.md)
  custom/    свои спрайты в стиле пака (нож, стены под все сочетания соседей)
docs/        архитектура и заметки
tools/       sprites/ — скрипты, которые рисуют свои спрайты (knife.mjs, walls.mjs)
.claude/     скил run-game для запуска и проверки игры агентом (Claude Code)
```
